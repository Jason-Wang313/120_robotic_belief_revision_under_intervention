# Hostile Prior Work

The hostile set contains belief revision, POMDP filtering, probabilistic robotics, shared autonomy, robot learning from correction, causal intervention learning, safety filters, and robot failure recovery threats. The strongest local threats include:

- Classical AGM belief revision and theory change.
- POMDP planning and probabilistic robotics.
- Robot learning from physical human correction.
- Shared-control and cooperative inverse reinforcement learning.
- Safety filters and safe reinforcement learning.
- Causal intervention reasoning.

Novelty boundary: the paper is not "belief updating for robots" broadly and not "revise when a human intervenes." The defensible contribution is gating physical belief revision with intervention evidence, counterfactual consistency, calibration, and fixed-risk acceptance.

Remaining hostile-review weakness: the evidence is local. A reviewer can still demand external benchmark transfer, real robot validation, released checkpoints/logs, and independent baseline implementations before accepting a main-conference claim.
