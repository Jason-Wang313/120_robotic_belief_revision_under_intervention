# Hostile Prior Work

The hostile set contains interactive VLA systems, action-conditioned world models, intervention-centric causal representation learning, belief-space safety filters, failure-aware RL, and human-in-the-world-model post-training. The strongest local threats include:

- PI-VLA: Adaptive Symmetry-Aware Decision-Making for Long-Horizon Vision-Language-Action Manipulation (2026)
- Generative World Explorer (2024)
- ACWM-Phys: Investigating Generalized Physical Interaction in Action-Conditioned Video World Models (2026)
- Failure-Aware RL: Reliable Offline-to-Online Reinforcement Learning with Self-Recovery for Real-World Manipulation (2026)
- Permissive Safety Through Trusted Inference: Verifiable Belief-Space Neural Safety Filters for Assured Interactive Robotics (2026)
- Causal Triplet: An Open Challenge for Intervention-centric Causal Representation Learning (2023)
- Hi-WM: Human-in-the-World-Model for Scalable Robot Post-Training (2026)

Novelty boundary: the paper is not generic interactive VLA, not generic belief-space planning, and not "ask a human more often." The defensible contribution is gating belief revision on interventions that expose violated physical assumptions.

Remaining hostile-review weakness: the evidence is local. A reviewer can still demand external benchmark transfer or real robot validation before accepting a main-conference claim.
